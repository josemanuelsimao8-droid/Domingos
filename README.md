# Domingos Cá — Site demonstrativo

Site estático em HTML, CSS e JavaScript.

## Estrutura
- `index.html`
- `styles.css`
- `script.js`

## Antes de apresentar ao cliente
1. Substituir as imagens demonstrativas por fotografias profissionais autorizadas do Domingos.
2. Confirmar biografia, serviços, imóveis, testemunhos e links sociais com o cliente.
3. Ligar a carteira de imóveis a dados atualizados.
4. Configurar domínio e analytics/SEO.
